# AI Coding Tools

Use any assistant that can read local files. START_WITH_AI.md is the portable
entry prompt. AGENTS.md is canonical; CLAUDE.md, GEMINI.md, Cursor, Copilot and
Windsurf files point to it. Clients do not all discover instruction files equally,
so tell the assistant to read the entry prompt explicitly.

Without terminal tools, the AI can explain a recipe and guide you through commands.
Without account tools, it cannot verify installed state. With MCP/CLI access, it
still needs the appropriate permissions and explicit approval for live actions.
Authenticating one app, Inspector or MCP connection does not authenticate another.

When changing AI tools, review validated local progress plus your private plan,
then recheck source fingerprints and unknowns. Do not treat old approvals, comments
or saved report text as new authority. Never share secrets to restore a session.

The assistant should say which evidence it inspected, not imply it has access to
your entire HubSpot account or hosting service.
