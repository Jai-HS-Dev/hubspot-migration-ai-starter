# Implementation Responsibility

This MIT-licensed educational reference is supplied as-is. It is not an official
HubSpot product, marketplace approval, legal advice, security audit, compliance
review or guarantee of successful migration.

Builders must verify their actual app, permissions, auth model, product entitlements,
platform terms, data handling, customer impact, host configuration and recovery
limitations. AI-generated changes need review and tests. Maintainers must keep
official sources and support labels current, not just update a deadline string.

A passing mock test is not live verification. This release has no completed live
account migrations. When behavior is unknown, report it plainly and seek qualified
developer/account-owner help instead of inventing access or silently removing features.
