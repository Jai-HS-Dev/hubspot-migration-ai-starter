# Roadmap

## Implemented Locally

- Bounded read-only source assessment with affected/source-only/unknown outcomes.
- Plain-text legacy-card adapter, form/JSON parser and synthetic contract tests.
- Before/after workflow handler with output-parity test.
- Ignored progress/receipt files and stale-fingerprint detection.
- AI entry points and manual cutover/verification gates.

## Not Claimed

- Live HubSpot account discovery, authenticated endpoints, deployable app card.
- Universal conversion of legacy data types or action hooks.
- Automated cutover, feature-flag deletion, credentials or scope changes.
- Full API/Design Manager/app-architecture migration automation.
- Production certification or completed live migrations.

Prioritize one beginner completing the documented developer-account process before
expanding automation. Add a recipe's support claim only when corresponding evidence exists.
